# 📊 Figuras e Gráficos

### N2 — Inteligência Artificial | IFCE Aracati

Esta pasta reúne as figuras geradas durante o experimento de classificação de tumores mamários, utilizando **Regressão Logística e Multilayer Perceptron (MLP)**.

As imagens foram produzidas no Google Colab e são utilizadas para visualizar e comparar o desempenho dos classificadores.

## 📁 Conteúdo

- **Curvas ROC:** comparação da capacidade de discriminação dos modelos.
- **Gráficos de limiares:** análise das alterações no desempenho conforme o limiar de decisão.
- **Falsos positivos e negativos:** visualização dos erros de classificação.
- **Matrizes de confusão:** distribuição dos acertos e erros de cada modelo.

## 🎯 Finalidade

As figuras complementam a análise experimental e servem como material de apoio para as tabelas, discussões e conclusões do artigo científico.

Os arquivos são disponibilizados em PNG para visualização e, quando exportados, em PDF vetorial para utilização no Overleaf.
